# Design notes and first playtest

Version 0.1 is a playable hypothesis, not a claim of balance. Its central bet
is that *Imperium*'s geography, campaign clock, and beam-versus-missile range
contest will create interesting strategic situations when individual attacks
use *Space Empires*' cleaner counters and d10 combat system.

## What came from where

- *Imperium*: the map, jump routes, refuelling chain, asymmetric income,
  reaction impulse, Glory clock, beam/missile armament, combat range,
  high-intensity missile fire, political interference, and wars separated by
  peace.
- *Space Empires: 4X*: hidden groups, printed ship statistics, firing classes,
  screening, fleet-size bonus, hull damage, maintenance by hull, fighters, and
  retreat.
- *Close Encounters*: Transports, Infantry, Space Marines, Heavy Infantry, Grav
  Armor, Militia, and class-based ground combat.
- *Traveller*: maneuvering pickets, laser point defense against missiles, and
  sandcaster defense against beams, abstracted to fleet scale.
- New: Armament Packages that map the old weapons onto the newer counters, the
  shared event deck, supply status, temporary militia bombardment, global
  interwar technology, and the simplified political tables.

## Intended fleet doctrines

The opening Imperial fleet has more missile reach and better Tactics, so it
should prefer Long Range. Terra has more dedicated beam hulls and fast Scout
pickets, so it should try to force Close Range. Mixed Imperial escorts trade
peak attack strength for flexibility and point defense. If both sides want the
same range most of the time, or if one doctrine is plainly dominant, the
package penalties and Picket ratings are the first balance knobs to adjust.

## Intentional exclusions

There is no exploration, colony growth, alien system, sublight movement,
terraforming, cloaking, mining economy, Titan, or technology purchase during a
war. These are good systems in their own game but pull attention away from a
short two-player frontier war or conflict with the Traveller-era fiction.

## Balance knobs

Change only one of these between tests:

1. Imperial starting Battlecruiser (remove it if early battles are hopeless for
   Terra).
2. Terran and Imperial income (especially the Imperial 10 RU budget).
3. Militia values of 1/5/8 (lower Worlds to 4 if invasions never succeed).
4. Card purchase cost (raise from 5 to 7 if card play dominates production).
5. Initial Glory (move to 6 if the Imperium loses by waiting too often).
6. Reaction allowances (2 Terran and 3 Imperial at present).
7. Mixed Package penalties and starting Point Defense (both sides begin at 1).

## First playtest procedure

Use the learning-game simplifications in *First Shots*. Do not tune the card
deck or political table during this first game. Record one line after each Game
Turn:

| Turn | Terra RU after builds | Imperial RU after builds | Ships lost T/I | Sites changed | Glory | Cards decisive? |
|---|---:|---:|---|---|---:|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |
| 4 | | | | | | |
| 5 | | | | | | |

After the game, answer:

- Could each player identify at least two plausible operational plans on turn
  one?
- Did the refuelling network create fronts, or did fleets bypass it too easily?
- Did either fleet have a reason to retreat and preserve expensive hulls?
- Did Imperial missile range and Terran beam range produce distinct, viable
  plans rather than a foregone result?
- Did Point Defense and sandcasters create useful choices without slowing each
  firing round?
- Was bombardment useful without making Ground Units irrelevant?
- Did Glory reward taking meaningful risks rather than gaming an Outpost?
- Which rule required an interpretation not present in the draft?

The next draft should be driven by those observations, not by adding more
systems.
